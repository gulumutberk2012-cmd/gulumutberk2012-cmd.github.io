UMUT BERK GÜL - KİŞİSEL PORTFOLYO

İÇERİK
- index.html: Site
- style.css: Sade ve mobil uyumlu tasarım
- script.js: Alt kısımdaki yılı günceller
- profil.jpg: Kendi fotoğrafını bu isimle eklemen gereken dosya (şu an pakette yok)

FOTOĞRAFINI EKLEME
1. Kullanmak istediğin fotoğrafın bir kopyasını site klasörüne koy.
2. Dosyanın adını profil.jpg yap.
3. index.html, style.css, script.js ve profil.jpg dosyalarını birlikte yayımla.
Fotoğrafı internette herkese açık yayımlayacağını unutma; uygun gördüğün bir fotoğraf seç.

ÜCRETSİZ YAYINLAMA
1. GitHub hesabına giriş yap veya hesap oluştur.
2. Yeni bir Public repository aç. Adı KULLANICIADIN.github.io olmalı; KULLANICIADIN yerine GitHub kullanıcı adını yaz.
3. index.html, style.css, script.js ve profil.jpg dosyalarını repository ana klasörüne yükle.
4. Commit changes ile kaydet.
5. Settings > Pages bölümünde Build and deployment altında Deploy from a branch seç.
6. Branch: main ve folder: /(root) seçip Save'e bas.
7. Yayınlanması birkaç dakika sürebilir. Adres https://KULLANICIADIN.github.io olur.

GOOGLE'DA ÇIKMASI İÇİN
1. Site internette açıldıktan sonra Google Search Console'a gir: https://search.google.com/search-console/
2. Site adresini mülk olarak ekle ve doğrulama adımlarını tamamla.
3. URL Denetimi alanına sitenin tam adresini yaz.
4. Google sayfayı kontrol ettikten sonra "Dizine eklenmesini iste" seçeneğine bas.
Google'da görünmesi birkaç gün veya daha uzun sürebilir; istek garanti değildir.

GİZLİLİK VE İŞ YERİ
- 15 yaşında olduğunu yazdık; doğum gününün tam tarihini yayımlamak zorunda değilsin.
- İş yerinin adını yalnızca kendini tanıtmak için kullandık. İş yerine ait logo, ekran görüntüsü, şirket içi veriler, proje ayrıntıları veya çalışma alanı fotoğraflarını paylaşmadan önce izin al.
- Kişisel telefon, ev adresi, okul bilgisi gibi özel bilgileri ekleme.
